| Attribute | Details |
|------------|---------|

| **Repository** | https://github.com/HeetSoni26/Autonomous-Traffic-Intelligence-System |

### Overview

TrafficIQ is my flagship AI research project focused on solving urban traffic congestion using decentralized intelligent agents.

Instead of relying on fixed traffic timers, the system continuously analyzes live traffic conditions through Computer Vision and dynamically optimizes signal timings using autonomous agents.

### Highlights

- YOLOv8 based vehicle detection
- ByteTrack object tracking
- Vehicle counting
- Queue estimation
- Emergency vehicle detection
- Multi-Agent communication via ZeroMQ
- Real-time dashboard
- Offline deployment
- Edge-native architecture
